# Roblox Multi Launcher

A simple Windows app for launching multiple Roblox instances and multiple accounts in one go.

Built for people who need to manage more than one Roblox session without manually opening everything one by one.

> Use this tool responsibly and always follow Roblox's Terms of Use and Community Standards.

## Features

- Launch multiple Roblox instances
- Launch multiple Roblox accounts
- Start several accounts in one session
- Simple account management
- Quick launch workflow
- Performance mode

## Performance Mode

## Requirements

- Windows 10 or Windows 11
- Roblox installed
- Internet connection :D

## Usage

1. Open the launcher.
2. Add or select the Roblox accounts you want to use.
3. Choose the accounts you want to launch.
4. Start the selected Roblox sessions.
5. Wait for each instance to open.
Do not close the launcher while it is still starting Roblox instances.

- Performance mode is still buggy
- Some Roblox instances may fail to launch
- Launch timing may vary depending on your PC and connection
- Roblox updates may temporarily break some functionality
- UI is currently questionable
